SQL 练习台与只读取数工具

我把一组业务场景题做成了浏览器里的 SQL 练习台，同时为本地项目提供查看表结构、指标口径和执行只读查询的工具。两者使用合成数据，重点是练习从问题到查询的过程。

在线：自己写 SQL，查看结果

页面提供 24 道练习题，涉及订单、优惠券、设备和退款等场景。加载示例数据后，可以选择题目、编写 SQL，并将结果与参考查询比对；表结构、关联关系和指标定义放在同一页面。

查询在浏览器内执行，页面本身不调用模型。结果区最多展示 200 行，比对最多使用取回的 1000 行。

本地：让模型按工具取数

下载包包含六个模型上下文协议（Model Context Protocol，MCP）工具，分别用于查看场景与表结构、搜索字段、读取指标定义、检查 SQL 和执行查询。

将工具接入支持 MCP 的客户端后，模型可以调用这些接口；项目中的数据库访问设置为只读。

一次取数，从口径到结果

1 · 看口径明确问题、时间范围与指标定义
2 · 查字段查看表结构与关联关系
3 · 检查 SQL编译查询并查看执行计划
4 · 只读执行返回结果，记录工具调用

我在意的两个细节

先写清指标。例如，净 GMV 使用实付金额减去退款金额，而不是直接汇总商品原价；表关联时也要注意一台设备可能对应多个账号。

执行前设置边界。本地查询使用只读连接，限制语句类型，并设置返回行数与超时。run_sql 默认返回 100 行、最多 200 行，超时设置为 5 秒。

范围与验证

数据为合成数据，结果仅用于演示，不能当作真实业务结论。项目使用 SQLite，不等同于 Hive 或 Spark。24 道题在当前数据上的结果值已独立复算，Q20、Q21 的口径错误已修正；排序与边界反例尚未全面验证。下载包中的历史提交记录仍仅包含 Q01，不代表模型作答成绩。
