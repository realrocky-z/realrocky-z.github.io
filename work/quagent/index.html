智能取数助手（SQL）

我把一组业务场景题做成了浏览器里的 SQL 练习台，同时为本地项目提供查看表结构、指标口径和执行只读查询的工具。两者使用合成数据，重点是练习从问题到查询的过程。

    24 道题在当前数据上的结果值已用独立 Python 聚合复算，并修正 Q20 的 GMV 字段和 Q21 的用户去重。验证不覆盖所有边界数据或模型作答能力；下载包的历史提交记录仍仅包含 Q01。

    在线页面不调用模型，SQL 在浏览器内执行。本地项目另提供六个 MCP 工具，接入支持 MCP 的客户端后可由模型调用。在线练习和本地取数是两个使用入口。

    开始练习

    加载示例数据后选择一道题，在编辑器中编写 SQL，点击「执行」查看结果。侧栏提供表结构、关联关系与指标定义；需要对照时可以查看参考写法。

    完整项目

    在线版用于编写 SQL 和比对结果。本地项目提供六个 MCP 工具，接入支持 MCP 的客户端后可由模型调用。

    下载后怎么运行
    1. 解压，确认目录里有 quagent/ 和 workbench/ 两个文件夹。
    2. 安装依赖，运行 python -m pip install "mcp[cli]"。
    3. 运行 python quagent/server/smoke_mcp.py，看到 ALL PASS 说明工具层正常。
    4. 参考 quagent/harness/install.md 配置支持 MCP 的客户端，使用包内场景和工具进行取数。

      先看数据长什么样

      写聚合之前先确认一行代表什么。订单表里一行是一单，设备表里一行是某个账号用过某台设备。同一台设备可以对应多个账号，所以算用户规模时要按 user_id 去重，不能数设备，也不能数订单行。

      本地项目提供的六个工具

      下载包通过模型上下文协议（Model Context Protocol，MCP）提供以下接口。模型可调用工具查看场景、表结构与指标定义，再检查或运行查询；在线页面不连接模型。

      查询限制与验证范围

      语句检查、只读连接和执行限制用于减少误操作，不能保证指标口径正确。在线版与本地版采用不同的执行方式，下面分别说明。

      查看语句检查示例
